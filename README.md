# UPSC Hub

🚀 **Live Demo:** https://upsc-hub-master-humi.vercel.app

UPSC Hub is a modern web platform designed to help UPSC aspirants access study resources, current affairs, articles, and educational content in one place. The platform provides a clean, user-friendly interface for learning and staying updated throughout the UPSC preparation journey.

## Features

* 🔐 User Authentication (Login & Signup)
* 📰 Current Affairs & News Updates
* 📚 Educational Articles & Resources
* 🎨 Modern Responsive UI
* ⚡ Fast and Interactive User Experience
* ☁️ Cloud Deployment
* 📱 Mobile-Friendly Design

## Installation

### Clone the Repository

```bash
git clone https://github.com/shreydev-15/UPSC-hub-master.git
cd UPSC-hub-master
```

### Frontend Setup

```bash
cd upsc_frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Environment Variables

Create a `.env` file and configure the required environment variables before running the application.

Example:

```env
SECRET_KEY=your_secret_key
DATABASE_URL=your_database_url
```
